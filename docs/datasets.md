# Datasets

## Status

No dataset has been selected, downloaded, or integrated yet.

Dataset selection, official source verification, license review, and
download/preparation scripts are planned for **Phase 1 — Dataset ingestion
and validation**, not this phase.

## Candidates under consideration (not yet verified or integrated)

- DAVIS 2017 (video object segmentation)
- MVTec AD (industrial anomaly detection)

These are candidates only. Before either is used, Phase 1 must:

1. Identify the official source.
2. Record dataset name and version.
3. Record the license and usage restrictions.
4. Confirm research/educational use is permitted.
5. Document findings here.
6. Provide download/preparation scripts — raw data will not be committed to
   this repository.

## Policy

- No dataset is committed to Git.
- No dataset is redistributed if its license restricts redistribution.
- `.gitignore` excludes `data/` and `datasets/` directories.
